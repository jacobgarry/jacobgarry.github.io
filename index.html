Selected Work

Engineering Projects

Selected aerospace, controls, embedded systems, and experimental testing projects.

PROJECT 01

NASA HASP Scientific Balloon Payload

Integrated and tested a high-altitude scientific payload designed to compare radiation effects on two NVIDIA Jetson computers, including one protected by a tungsten-filled conformal coating. Supported power, thermal, communication, software, and system-level testing through NASA integration.

Flight Systems Embedded Computing Integration Testing Thermal Vacuum
PROJECT 02

Nonlinear Modeling and Control of a Pneumatic Rotary System

Developed a nonlinear Simulink model using measured thruster data, actuator dead zones, saturation, gravity, damping, pneumatic dynamics, and encoder response. Designed and evaluated a filtered PID controller for stable and unstable operating points using root locus, Bode margins, sensitivity, and disturbance testing.

MATLAB Simulink PID Control Dynamic Modeling
PROJECT 03

Automated Wind-Tunnel Measurement System

Developed an automated measurement rail for collecting airflow data across a fan-array test section. Integrated a stepper motor, distance sensor, differential-pressure sensor, limit switch, and ESP32-based control system to execute repeatable spatial measurements.

ESP32 Automation Instrumentation Wind-Tunnel Testing
PROJECT 04

Active Airbrake System for High-Powered Rocketry

Contributed to the design, fabrication, integration, and testing of an actively controlled aerodynamic airbrake system for competition rockets. The project combined mechanical design, embedded control, servo actuation, flight instrumentation, and post-flight data analysis to improve apogee accuracy and system reliability.

High-Powered Rocketry Mechanical Design Embedded Systems Flight Testing
