Radiation-Mitigation Payload for High-Altitude Computing

A scientific balloon payload developed to compare two identical NVIDIA Jetson computers—one protected by a tungsten-filled conformal coating and one left uncoated—while both run the same computational workload near 120,000 feet.

Mission Concept

A controlled comparison of radiation protection for embedded computing.

At high altitude, reduced atmospheric shielding increases exposure to energetic particles that can corrupt memory, interrupt software, and degrade electronics. The payload addresses that problem through a side-by-side experiment using two otherwise identical NVIDIA Jetson computers.

Both computers execute the same DGEMM benchmark and report performance and system-health data. One Jetson is coated with MOICC, a tungsten-filled conformal coating intended to absorb radiation, while the second Jetson provides an uncoated control for comparison.

The experiment is supported by a Raspberry Pi flight computer, power converters, relay-controlled heaters, environmental sensors, onboard data logging, and an RS-232 link to the HASP ground-station interface.

Project objective

Determine whether the MOICC coating produces a measurable improvement in computing reliability and performance in a near-space radiation environment.

Integrated Payload

Mechanical, electrical, thermal, and software systems had to work as one.

The payload combined commercial embedded computers with custom mounting, power distribution, heater control, communications, and flight software inside the dimensional and operational constraints of the HASP platform.

Power Distribution

Integrated the 28-volt input, DC converters, relays, grounding, and startup sequencing required to power the Pi, both Jetsons, and heater circuits reliably.

Thermal Management

Used independently controlled heaters and temperature telemetry to protect the computers through the cold portions of ascent and float.

Flight Communications

Established 1200-baud RS-232 communication with the NASA interface and supported Ethernet, SSH, and UDP links during development.

Autonomous Software

Configured Linux services and flight scripts to start automatically, monitor system health, run benchmarks, log data, and respond to ground commands.

Environmental Validation

The completed payload passed NASA integration testing.

At the Columbia Scientific Balloon Facility in Palestine, Texas, the payload was mounted to the HASP test hardware and operated continuously inside a thermal-vacuum chamber while the team monitored power, temperatures, communications, and computer status.
